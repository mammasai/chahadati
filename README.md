# 🌳 شجرة المسار التفاعلي لمنصة "المستشار" (AlmostachAR Workflow Tree)

```text
[المستوى 0: البوابة الذكية وفحص النية]
   └── 🤖 ترحيب مبادر وفحص النية (Intent Guardrails)
         ├── ❌ خارج نطاق Arabic NLP ──> اعتذار لطيف + توجيه لنطاق التخصص
         └── ✅ داخل نطاق Arabic NLP ──> الانتقال لاختيار مستوى المستخدم (مبتدئ / خبير)

[المستوى 1: تصنيف المشروع وبناء الهيكل]
   └── 🎛️ عرض بطاقات أنواع المشاريع التفاعلية:
         ├── [😃 1. تصنيف المشاعر والآراء (Sentiment Analysis)]
         ├── [📰 2. التصنيف الموضوعي ورصد الإشاعات (Text Classification)]
         ├── [📝 3. التلخيص التلقائي للنصوص (Summarization)]
         ├── [🔍 4. استخراج الكائنات المسمات (NER)]
         └── [🔤 5. التشكيل والتحويل الصوتي (Diacritics & TTS)]
   └── 📄 توليد وثيقة متطلبات مبدئية تلقائية (Project Blueprint)

[المستوى 2: إدارة البيانات، المحقق الآلي، وموازنة اللهجات]
   └── 📁 خيارات توفير البيانات:
         ├── 🔘 رفع ملف خاص (CSV / JSON / Excel)
         │     └── 🕵️ المحقق الآلي: فحص ترميز UTF-8، الرموز، وكثافة المفردات
         │           └── ⚖️ مساعد موازنة اللهجات (عند اكتشاف اختلال بين الفصحى والعامية):
         │                 ├── [🎲 توليد بيانات تعويضية اصطناعية (Synthetic Augmentation)]
         │                 └── [🔄 تطبيق إعادة العينات (Re-sampling)]
         ├── 🎲 توليد بيانات وهمية/تجريبية (Synthetic Dataset Generator)
         └── 🌐 تصفح مصادر ومكتبات بيانات عربية جاهزة (Hugging Face / Corpora)

[المستوى 3: معمل البيانات التفاعلي للتنظيف والصرف]
   └── 🧹 خيارات المعالجة الصرفية العربية:
         ├── التطبيع الذكي وتوحيد الحروف
         ├── إزالة أو إبقاء التشكيل
         └── التجذير والتحذيع (Farasa / CAMeL Tools / Assem)
   └── 🎛️ معمل البيانات التفاعلي:
         ├── 👁️ أزرار معاينة حية: [عرض النص الأصلي] ↔️ [النص بعد التنظيف]
         └── 🎚️ شريط سحب (Slider) للتحكم في معايير التنظيف ورؤية تأثير الكثافة اللغوية لحظياً

[المستوى 4: تمثيل النصوص، النماذج، ومستشار البنية التحتية]
   └── 🏛️ بطاقات اختيار النماذج العربية:
         ├── [⚡ TF-IDF + Logistic / XGBoost] (خفيف وسريع)
         ├── [🏛️ AraBERT] (للفصحى والمقالات)
         ├── [🐪 CAMeLBERT] (للهجات واللغة المختلطة)
         └── [🐦 Marbert] (لتغريدات تويتر والنصوص الدارجة)
   └── 💡 مستشار البنية التحتية: اختيار بيئة التدريب (جهاز محلي / Colab / GPU) مع تقدير الذاكرة ووقت التدريب

[المستوى 5: المصحح التفاعلي أثناء التدريب (Self-Healing Engine)]
   └── 🛠️ تشغيل الأكواد (نسخ وتشغيل)
         └── 🚑 المصحح التفاعلي المستمر:
               ├── لصق رسالة الخطأ (مثل: تعارض مكتبات أو نفاد ذاكرة CUDA)
               └── 🤖 تحليل الخطأ وتقديم الكود المُصحح فوراً بنقرة زر

[المستوى 6: التقييم الاستشاري وتصدير حزمة المشروع]
   └── 📊 بطاقات الأداء اللغوي الاستشارية (تحليل الدقة وشرح الأخطاء ومعالجة Overfitting)
   └── 📦 مخرج المشاريع التلقائي (One-Click Exporter):
         └── زر [📦 تصدير حزمة المشروع Zip] لتحميل الأكواد مقسّمة (`preprocess.py`, `train.py`, `predict.py`) مع ملف `requirements.txt` وواجهة Streamlit تجريبية
